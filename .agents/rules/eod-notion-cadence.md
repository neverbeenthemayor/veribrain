# Mandatory End-of-Day (EOD) Cadence — GitHub First, Then 6 Notion HQ Sections

At EOD (after 1 single batched `docs(...)` commit when not in code freeze), CPM verifies all 6 Notion Founder HQ sections:
1. **Comments:** Post concise EOD push-notification summary (verified `main`/`staging` SHAs, test/security/FinOps status).
2. **Executive Pulse:** Update date, live SHAs, Gate burn-down, CI/FinOps metrics.
3. **Owner Action Checklist:** Check off `[x]` completed Tier 1 console decisions and refine pending items.
4. **Master Feature & Backlog Tracker:** Sync `PM-*` statuses/points (`Gate 1-4` + `Post-Release Gate 1-3`).
5. **Weekly Retros & Release Train Log:** Log Monday Review, Tuesday Soak, Wednesday Release, or Friday Retro.
6. **Child Pages:** Update Tech Spec ONLY when new features ship; keep active registers `< 8,192 B`.
