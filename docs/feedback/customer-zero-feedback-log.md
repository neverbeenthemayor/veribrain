# VeriBrain — Customer-Zero Peer Feedback & Innovation Log

- **Customer-Zero Peer Source:** Customer-Zero CPM (`customer-zero-mcp` MCP server)
- **Intake Owner:** VeriBrain CPM
- **Sanctioned Dual-MCP Feedback Inbox Protocol (`AGENTS.md` Rule #3):**
  - Antigravity enforces project isolation across independent root workspaces (`cross-project messaging is not allowed`).
  - **Write Side (Customer-Zero -> VeriBrain):** Customer-Zero's CPM submits field feedback through the shared `veribrain` MCP server via `veribrain_record_hypothesis` (`id: "HYP-PP-FB-<slug>"`, `roles: ["cpm"]`, `ttl_days: 7`, automatically quarantine-scrubbed into `<veribrain-repo>/.brain/hypotheses/`).
  - **Read Side (VeriBrain -> Customer-Zero & Inbox):** VeriBrain CPM reads its own `.brain/hypotheses/HYP-PP-FB-*.json` inbox (`node ./dist/cli.js diff --since 24h`) AND calls strictly read-only `veribrain_status` + `veribrain_compile_context(role="veribrain-feedback", env="local")` on `customer-zero-mcp`. ZERO file reads/writes in external repositories; ZERO write MCP calls against `customer-zero-mcp`.
- **Scoring Rubric (`.agents/skills/feature-request-intake/SKILL.md`):** ICE Score = `(Impact x Confidence x Ease) / 125` (`1–5` per axis) + Modified Fibonacci points (`1 / 2 / 3 / 5 / 8 / 13`), grouped into `<= 20-pt` `Post-Release Gate 1+` (`PRG-1+`) waves.
