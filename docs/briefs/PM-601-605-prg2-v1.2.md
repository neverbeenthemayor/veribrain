## 1. Story Specs (`18/20 pts`)

### `PM-601` (`5 pts`) — Zone `A0` + `A1` Constitutional Prefix Split
- Support `VALID_SCHEMA_VERSIONS = ["1.0", "1.1"]` (`SCHEMA_VERSION = "1.0"` remains default).
- Add `ZoneALayout = "legacy" | "split"` and `ZONE_A0_BOUNDARY_MARKER = "<!-- VERIBRAIN:ZONE_BOUNDARY:A0_END -->"`.
- Add optional `zone_a_layout?: ZoneALayout` in `BrainConfig`, `CompileOptions.zoneALayout`, CLI `compile --zone-a-layout legacy|split`, and MCP `veribrain_compile_context` (`zone_a_layout`).
- Precedence: `options.zoneALayout ?? config.zone_a_layout ?? (config.schema_version === "1.1" ? "split" : "legacy")`.
- In `"split"` mode:
  - `zone_a0` renders ONLY shared constitutional rules (`d.roles.includes("*")`), sorted `(priority ASC, id ASC)`, with **zero role name anywhere in `zone_a0`** so `zone_a0_sha256` is 100% byte-identical across all Chief roles.
  - `zone_a1` renders role identity + role-specific active `DECIDED` rules (`!d.roles.includes("*")`).
  - `zone_a = "${zone_a0}${ZONE_A0_BOUNDARY_MARKER}\n\n${zone_a1}"`, `zone_a_sha256 = sha256Hex(Buffer.from(zone_a, "utf8"))`.
  - Include `zone_a_layout: "split"` in `semantic_hash` and raise `kv_cache_floor_advisory` when `zone_a0_tokens_est < 1024`.
- Emit additive `CompileResult` fields (`zone_a_layout`, `zone_a0`, `zone_a1`, `zone_a0_sha256`, `zone_a0_bytes`, `zone_a0_tokens_est`, `zone_a1_bytes`, `zone_a1_tokens_est`) in both modes while keeping legacy `1.0` `zone_a` & hashes byte-identical.

### `PM-602` (`5 pts`) — `veribrain attest-test` (`OBS-VERIFY-*` `$0`-LLM Gate Receipts)
- Fail closed (`EXIT_PROVENANCE_VIOLATION = 4`) when `isAgentEnvironment()` is true.
- Execute via `spawnSync(..., { shell: false })` accepting `-- <executable> [args...]` or `--cmd <command>` (+ repeatable `--arg`). Reject shell metacharacters `[;&|<>`$\r\n(){}]` in `--cmd`. Resolve Windows `npm`/`npx` via `npm-cli.js`/`npx-cli.js` under Node's bin without `cmd.exe`.
- Enforce bounded timeout (default `120_000 ms`, max `600_000 ms`, `--timeout <ms>`) and `maxBuffer: 4 * 1024 * 1024`.
- Compute `output_sha256` and `git_diff_stat_sha256` (`git diff --stat HEAD`, fallback `"no-git"`). Never echo raw command output into the receipt.
- Validate `^OBS-VERIFY-[A-Za-z0-9._-]{1,50}$` (auto-generate `OBS-VERIFY-<slug>-<env>` if omitted), write Tier 2 `observed/<claimId>.json` (`issuer: "verifier-script"`) on pass (or fail only with `--record-failure`, still returning `EXIT_ERROR = 1`), and support `--dry-run`, `--ttl` (default `86400`), `--ttl-mode`, `--roles` (`*`), `--priority` (`P1`), `--format json|text`.

### `PM-603` (`3 pts`) — `veribrain check-citations` (Zero-LLM Doc Drift Auditor)

Reject repo-escaping paths/symlinks and `isBlockedSystemOrIsolationPath`; cap `500` files / `512 KB` per file.
- Skip fenced code blocks by default (`--include-code-blocks` opt-in) and ignore placeholder IDs (`DEC-NNN`, `DEC-###`, `DEC-XXX`, `DEC-000`, `OBS-NNN`, `OBS-XXX`, `OBS-000`, `DEC-ID`, `OBS-ID`, `*-EXAMPLE`, `*-SAMPLE`).
